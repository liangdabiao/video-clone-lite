# Seedance 带货视频提示词知识库

来源： 六篇实战方法论文档的蒸馏。
本文件是 skill 的领域知识内核，`replicate.py` 的 system prompt 取其核心子集，
完整规则以此文件为准。

## 一、S-A-C-S-C 五要素框架（拆解与复刻的万能公式）

| 要素 | 内容 | 规范 |
|---|---|---|
| **S**ubject 主体 | 人物/产品 | 人物四层：身份标签→外貌特征→服装（颜色具体）→气质；表情用物理描述（"嘴角微微上扬"而非"开心"）；产品标注色号（RGB）、"材质+纹理"双重描述 |
| **A**ction 动作 | 主体做什么 | 拆成 3-5 个关键帧步骤（拿起→凑近→涂抹→放下）；写慢、写连续、写过程；标注幅度（轻微/中等/大幅，越大越易崩）与交互 |
| **C**ontext 场景 | 在哪里 | 三层：场景类型→时代风格→环境细节（"复古咖啡馆，木质桌椅自然纹理，午后阳光侧逆光，丁达尔光效，咖啡杯蒸汽缓缓上升"） |
| **S**hot 镜头 | 怎么拍 | 景别（特写/近景/中景/全景/远景）×视角（俯拍/平视/仰拍）×景深（浅=背景虚化/深=前后清晰）+ 运镜 |
| **C**olor/mood 情绪 | 什么感觉 | 色调（暖=温馨/冷=科技/莫兰迪=高级）+ 饱和度（高=活力/低=质感）+ 对比度（高=戏剧/低=柔和） |

五要素缺一个，AI 就在该维度自由发挥，翻车概率翻倍。

## 二、五大模块提示词结构（带货完整版）

1. **基础参数**：`15秒，9:16竖屏，1080P高清，30fps帧率，电影质感，画面丝滑无卡顿，无抖动无闪烁，细节丰富，锐度清晰，色彩自然还原，主体结构正常比例自然`（跨境TikTok用16:9+4K；直播间贴片用1:1+720P；慢动作用60fps但双倍积分）
2. **镜头语言**：光影+运镜+景别三位一体
3. **核心主体**：@参考图锁定 + 物理属性精准描述
4. **商业场景**：使用场景、核心动作、核心卖点——每个镜头服务"卖货"
5. **强制约束**：产品无穿模无变形、轮廓清晰、颜色校准无偏色、人脸自然五官对称无脸崩

## 三、反向拆解十招（analyze 的实现依据）

1. **运镜**：三问（动不动？推拉/平移/环绕？快慢？）→ 标准术语。运镜三级跳：稳定优先，缓慢动镜次之，复杂运镜最后
2. **镜头感**：景别×视角×景深三维组合
3. **场景真实感**：物理细节（材质/交互）→ 光影系统（自然/人造、光位、丁达尔）→ 氛围（天气/时间/空间）
4. **动作逻辑**：时序（3-5关键帧）+ 幅度 + 交互（风吹发丝、手触产品）
5. **色彩**：色调→对比度→饱和度三参数
6. **节奏**：镜头时长分配（短视频每镜头3-5秒）→ 转场方式（硬切/淡入淡出/溶解）→ 情绪曲线（平静-上升-高潮-回落）
7. **主体塑造**：外貌从大到小逐级 + 表情物理化 + 服装全细节
8. **负面提示词**：防翻车保险（见第六节）
9. **参考系统**：@图/@视频/@音频语法；真人照片需打码/抠脸/转插画过审
10. **整合**：S-A-C-S-C 拆完 → 分镜表 → 提示词

三原则：**可见性**（物理细节替代抽象词）、**精准性**（专业术语替代模糊描述）、**完整性**（五要素齐全）。

## 四、带货专属规则

### 4.1 流量结构：黄金3秒钩子 + 中段种草 + 结尾促单

### 4.2 五种带货框架
口播介绍型（通用爆款）/ 场景代入型（沉浸种草）/ 对比测评型（信任建立）/ 细节种草型（专业微距）/ 剧情植入型（软广）

### 4.3 自然流 vs 付费流（五维差异）

| 维度 | 自然流（种草出单） | 付费流（千川转化） |
|---|---|---|
| 镜头 | 跟镜/移镜/平视，中景近景 | 极致特写/希区柯克变焦 |
| 光影 | 自然光柔光暖色调，烟火气 | 硬光侧逆光，青橙冷调，电影级 |
| 叙事 | 痛点提问/结果前置，种草结构，舒缓 | 视觉奇观/福利钩子，对比结构，极快 |
| 音效 | 环境音/轻柔ASMR/轻音乐 | 重音打击卡点/明快纯音乐 |
| 标注 | "自然种草、无过度营销元素" | "千川素材、结尾行动号召、高转化节奏" |

自然流核心公式：真实场景+精准痛点+具象卖点+自然体验（1000-3000 精准播放稳定出单，好过高播放泛流量）。

### 4.4 品类专属优化
- **美妆**：涂抹质感（无卡粉无飞粉显色均匀）、膏体无断裂
- **食品**：食欲感交互（掰开酥脆掉渣声响清脆）、色泽鲜亮无碎裂
- **3C**：操作顺畅（磁吸精准无卡顿）、金属质感无刺眼反光
- **家居**：功能实现过程（水雾细腻均匀覆盖）、运行自然无卡顿
- **服饰**：垂坠感版型（自然褶皱无僵硬、版型宽松不紧绷）

### 4.5 通用物理交互关键词
手指轻触无凹陷 / 液体缓慢倾倒无飞溅 / 布料自然垂坠有褶皱 / 膏体推开无结块 / 金属开合顺畅无卡顿

### 4.6 @参考图实操
1-3 张产品图（正面/侧面/细节，自然光纯色背景，抠图锐化）；提示词开头 `@产品参考图1`；加还原度约束"产品外形1:1还原参考图，颜色与实物一致（RGB:…），纹理细节完整呈现"。参考图比纯文生视频废片率低 2/3。

## 五、字数与节奏法则

- 单镜头提示词 ≤200 字（建议 120，正好 15 秒口播最佳字数）
- 15 秒全片整段 ≤800 字（勿超 1000）
- 多镜头分段：每段 ≤200 字，总体 ≤1500 字
- 单镜头单重点；一条视频只用一种主运镜；5 秒内不切换光影风格
- 时间控制三法：时间锚点（0-5秒:…；5-10秒:…）/ 画面编号（镜头A/B）/ 动作流连接词
- "慢—快—慢"黄金节奏；连续动作写过渡（"从跳跃直接过渡到翻滚，保持连贯"）
- 动作修饰词：缓慢、轻柔、连贯、自然、流畅、不僵硬

## 六、负面提示词模板

英文万能版：
`low quality, blurry, deformed, mutated hands, extra limbs, bad anatomy, jittery motion, physics error, face distortion, clothing glitch, watermark, text, logo, no extra fingers, no asymmetrical features`

中文约束版（拼在正向提示词尾部）：
`人脸自然五官对称无脸崩无变形，人体结构正常比例自然，同一角色服装一致，产品无穿模无变形，颜色校准无偏色，画面无抖动无模糊无重影无闪烁`

## 七、避坑清单

1. 复杂多人互动、打架跑跳、大幅度舞蹈——极易崩，禁用
2. 模糊词（好看/很酷/高级/有质感）——等于没写
3. 矛盾要求（超高速+极度稳定）——无法同时满足
4. 一镜多运镜、一镜多卖点——信息过载
5. 素材要 @：不@等于白传；"参考@视频1运镜"≠"把@视频1里的人换成X"（参考≠编辑）
6. 优化用单变量修改法 + 小样先行（720P验证后再1080P）+ 版本号迭代（V1.0/V1.1）

## 八、即梦平台要点

- 网页版功能最全（智能多帧2.0/无限画布/多图层/批量/Agent模式）；全能参考模式优先
- Seedance 2.0 fast：场景简单、≤2分镜、人物少时够用且省积分
- 多模态输入：图≤9、视频≤3（共≤15s）、音频≤3（共≤15s），文件共≤12 个；生成 4-15 秒，自带音效配乐
- 时长选择 4-15 秒；15 秒口播约 120 字
