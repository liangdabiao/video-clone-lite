# video-clone-lite 使用说明（人话版）

> 一句话：**你给我一条别人的爆款视频 + 你的产品照片（想要的话再加一张你的照片），
> 我还你一条结构一模一样、但主角和产品都换成你的新视频。**

---

## 它能帮你做什么

比如你在抖音刷到一条卖精华的开箱视频卖爆了：

```
别人的视频：外国博主 → 精华泵瓶 → 15秒
你的视频：  中国女生 → 你的口红 → 15秒（结构节奏完全一样）
```

不用学剪辑、不用装专业软件、不用懂任何技术。整个过程像点外卖：
**下单 → 等几分钟 → 收货**。

## 使用前，你要准备的东西

| 要什么 | 干什么用 | 大概花销 |

费用参考（实测）：一条 **15 秒**的成品视频，大约 **4-6 元人民币**。
先给你看 3 秒小样确认效果，满意再做完整版，不满意不花钱。

## 整个过程是怎样的（你只需要做三件事）

1. **把视频给我**，说一句"照这个给我做一条，产品换成我的"。
   我会先看懂它：几个镜头、每个镜头几秒、人物在做什么、说了什么话。
2. **给我素材**：产品照片（必须）、你的照片（想真人出镜就给，不给我就用 AI
   生成一位模特）。
3. **等 30 分钟左右**，我会给你一条成品视频 + 一份"施工记录"
   （每一步做了什么、花了多少钱，全都写得清清楚楚）。

---

## 这条流水线是怎么运转的（给想了解原理的你）

```
第1步 看懂原片    AI 直接"观看"整段视频，输出分镜表：
                  哪几秒是拆箱、哪几秒是特写、动作先后顺序、说了什么话
第2步 备好新料    用 AI 画出新主角的样子、新产品的样子
第3步 逐镜重拍    按分镜表一个镜头一个镜头生成：
                  新主角照着原片的动作，用你的产品演一遍
第4步 拼接成片    按原片的节奏剪好、拼好，输出成品
```

每一步的中间产物都保存着——**哪个镜头不满意，只重做那一个**，
不用整条重来，也不重复花钱。

## 它擅长的 / 它做不到的（诚实版）

**擅长：**
- 带货/种草类实拍视频的同款复刻（开箱、测评、使用展示）
- 保留爆款的节奏和"感觉"，换上你的产品和出镜人
- 便宜、快：单条几块钱，半小时级别
- 中途随便改：哪镜不行改哪镜

**做不到 / 不擅长：**
- 画面质感是"AI 生成"的，比真拍摄**略柔和**，放大看有细节差异
- 台词口型：模型会尽量让人物说话，但说话内容需要你亲自听验
- 复杂图文特效类视频（花字满天飞、动画排行榜那种）目前做不了
- 不保证 100% 成功：偶尔某个镜头生成失败，重试即可（失败不扣费）

## 常见问题

**Q：我的照片安全吗？**
照片只用于生成你自己的视频。不要把不希望被 AI 使用的人物照片交进来。

**Q：生成的视频能商用吗？**
视频由第三方 AI 平台生成，商用前请确认平台条款，并确保你不冒充原视频作者。

**Q：为什么有时候某个镜头会失败？**
AI 生成有一定失败率（平台显示约三分之一概率要重试）。脚本会自动重试，
失败不扣费。连续失败我会停下来和你商量换方案，不会闷头乱烧钱。

**Q：费用怎么算？**
按生成时长计费，720p 约 **0.2 元/秒**。一条 15 秒的片子（含重试损耗）
通常 5 元上下。每次花钱前都会先向你报价，确认了才动手。
